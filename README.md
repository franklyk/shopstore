# Arquitetura

A arquitetura e o fluxo-mestre de implantação do ShopStore estão documentados em [`docs/architecture.md`](docs/architecture.md).

# Ciclo de desenvolvimento do ShopStore

### 1. Fazer funcionar — implementar a funcionalidade e garantir que o fluxo principal esteja correto.

### 2. Fazer ficar seguro — validar permissões, autenticação, dados recebidos, integridade e possíveis falhas de segurança.

### 3. Fazer ficar rápido — analisar consultas ao banco, carregamento de páginas, requisições e uso de recursos.

### 4. Fazer ficar bonito — melhorar a interface, a organização visual, a responsividade e a experiência de uso.

### 5. Revisar e repetir — identificar problemas, priorizar correções e reiniciar o ciclo quando necessário.
